## Summary

Add a GitOps dispatch job to each of the three independent image pipelines, gated by `DEPLOYMENT_MODE=gitops` so Docker and GitOps deploy jobs are mutually exclusive. Configure Nginx to use the container's DNS resolver on Docker or K3s. Build Backoffice with the `/backoffice/` base path in GitOps mode while retaining the existing Docker mode.

## Before merge

Land the DevOps image updater first. Set repository variables `DEPLOYMENT_MODE=gitops`, `VITE_BACKOFFICE_URL=/backoffice/`, `VITE_GALLERY_URL=/`, and preserve `DOCKERHUB_USERNAME=otakuict`. Add `GITOPS_DISPATCH_TOKEN` as a repository secret limited to the DevOps repo with Contents: Write. Do not place tokens in Git or chat.

This PR does not create a public hostname. K3s replicas remain zero until reviewed rollout PRs.
